## Featured Projects

### ModiFly Cockpit — Unmanned Systems Lab
Visual node-editor cockpit application for autonomous drone control. Built with C++, ImGui, ImNodes, SDL3, and OpenGL. Features SITL process spawning, MAVLink RPC integration, and a live controller data display.

### PlanterBox — Automated Hydroponic Monitor
Full-stack IoT system for automated plant monitoring and control. ESP32 firmware handles pH, PPM, temperature, humidity, and water level sensors with automated pump/light scheduling. Next.js dashboard with real-time charts, plant profiles, and a captive-portal WiFi setup.

### Music Glove — PIC16F1829
Wearable embedded music controller using flex sensors mapped to musical tones, Morse code, and signaling modes. Programmed in C with MPLAB X IDE. **3rd Place — Microcomputer Systems I Final Project, Spring 2023.**

### Spotify Controller — ESP32
Touchscreen Spotify remote built on the Elecrow CrowPanel display. Features album art rendering, marquee track titles, playback controls, and live track syncing via the Spotify Web API over WiFi.
